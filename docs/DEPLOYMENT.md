# Deployment Contract

This source release includes the complete foreground campaign chain. Do not execute
upstream example launchers as resource authorization. The CPU command runs only
synthetic project tests, not upstream simulator tests.

## Implemented Components

The source-bound restore context, physical/RNG comparator, replay, auxiliary and
camera comparisons, teacher Journal, public-camera budget, independent native25
decoder, three-condition readback and exclusive manifest transaction are now
included. `continuation.SourceContinuation` composes replay, persisted restore
evidence, public camera metadata and journal attachment before teacher takeover.
The original production Model/worker/takeover, private-network OCI stage,
provider-stop propagation and owned supervisor are also included. Native
construction hooks preserve the planner/physics split and initial layout checks.
The reserved-source preparation/Native-child API writes terminal results and
retains cleanup failures. See [runtime policy](RUNTIME.md).
The foreground parent now provisions the pinned environment, holds one simulator
lock inherited by its child, waits under the original deadline and cleans only
its owned process group. Conveyor extension pins and the source-only Vulkan
compatibility layer are supplied through explicit external deployment bindings.

These implementations retain the original deployed checks. Source/owner/root/
budget/rule pins are supplied externally. New wrappers are not byte-identical
historical launchers; changing a binding is not proof of production equivalence.
See [external contracts](RESTORATION.md).

## Campaign Integration

`campaign.runner.Campaign` connects the original source assembly/reservation,
frozen-DM process, full baseline readback, source admission, teacher parent,
three-condition publisher and ledger. `campaign.store.Store` supplies durable
locked CAS publication and explicit metadata-only reconciliation. Source
reservation remains independent of process exit and saved-data qualification.
See [campaign contracts](CAMPAIGN.md) for configuration and commands.

Acceptance consists of deterministic original-source comparisons, synthetic
CPU regressions, packaging and privacy checks. It does not claim measured live
yield, throughput, simulator readiness or model access. Real episode generation
is deliberately outside this release's acceptance scope.

## External Runtime

Keep private configuration outside the project. Before real execution, verify
the currently authorized host, execution owner, scheduler allocation, GPU
identities/headroom, peer processes, disk and memory, licensed simulator/assets,
policy weights and authorized model access. Set devices explicitly. No shipped
configuration grants resources or permits interference with peer jobs.

The deployment doctor checks dependency presence and pins only. The deliberately
incomplete example must fail it. It cannot authorize a launch.
See [runtime components](RUNTIME.md) for the external Vulkan build and extension
contracts. Installed libraries/assets and execution permission are not shipped.

## Existing Native Integration

An integrating caller owns a fresh official Native task and the original frozen
policy. Configure `recording.rtx_profile` before reset, validate the actual
source seed/layout and runtime, then initialize the original recorder with
`recording.common.initialize_recording`. Supply an explicit renderer device and
actual runtime evidence capture. Physics/RNG/camera checks remain mandatory.

`baseline.runtime` supplies the original OpenDM evaluator to
`collection.run_baseline`; `baseline.reader` performs complete independent
readback after the parent wait. The loop's raw success result is
unqualified. For an independently admitted failed source, use `RestoreBinding`
to prepare the original pinned source context and `SourceContinuation.restore`
on a fresh owned task/recorder. Do not use the older generic
`collection.replay_prefix` seam as a replacement for the original comparator.

Only after restoring t1 may the caller construct the original unstarted teacher
model using the actual owner/counter context and isolated session binding.
`SourceContinuation.bind_teacher` installs the camera observer and Journal,
loads only causal history, checks provider-stop evidence, and calls the original
teacher takeover under its sole-owner guard. `run` retains the original native
and wall budgets, and returns an unqualified native outcome.

The caller must close and wait for its own recorder, worker and task in a
primary-error-preserving `finally` path. An unknown action outcome or cleanup
failure is never permission to retry an episode. Persist the original terminal
result and diagnostics outside the project. Run independent `robofate settle`
only after recording ends; its data acceptance does not certify API lifecycle,
process cleanup, source admission or quota/ledger registration.

## Privacy

Run plans, source IDs, host/owner information, device selections, logs, frames,
restore profiles, ledgers, results, credentials and deployment pins live outside
the checkout. The source index contains relative code/resource paths, sizes and
hashes only. Do not distribute the recovery snapshot or private audit mapping.
